# 新人指引

欢迎加入 SAU 无人机团队！本文档帮助你快速了解团队、熟悉工具，并顺利开始工作。

## 1. 加入前的准备

1. 阅读 [团队规范](regulations.md)，了解团队的基本行为准则。
2. 准备好以下工具和账号：
   - GitHub 账号（用于代码与文档协作）
   - 团队即时通讯工具账号（微信/飞书，由负责人邀请）
3. 申请加入对应的 GitHub Organization：`SAU-UAV-team`。

|------|------|
| [SAU-Docs](https://github.com/SAU-UAV-team/SAU-Docs) | 团队文档（本仓库） |

## 3. 工作流程

### 修改文档或代码

```bash
# 1. Fork 或克隆对应仓库
git clone https://github.com/SAU-UAV-team/<仓库名>.git

# 2. 创建新分支
git checkout -b feat/your-feature-name

# 3. 进行修改后提交
git add .
git commit -m "feat: 简要描述本次修改"

# 4. 推送并提交 Pull Request
git push origin feat/your-feature-name
```

### Pull Request 要求

- 标题清晰描述本次改动。
- 在描述中说明改动原因和影响范围。
- 至少等待一名成员 Review 通过后合并。
