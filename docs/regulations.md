# 团队规范

本文档规定了 SAU 无人机团队的基本行为准则与工作规范，全体成员须遵守。

## 1. 代码与文件管理规范

- 所有代码提交须附有清晰的 commit message，简要描述本次变更内容。
- 禁止直接向主分支（`main`/`master`）推送代码，须通过 Pull Request 并经过至少一名成员 Review 后合并。
- 文件命名使用小写字母加连字符（kebab-case），例如 `flight-controller.md`。
- 不得将敏感信息（密钥、密码、IP 地址等）提交至代码仓库。

## 2. 会议与沟通规范

- 定期例会须提前通知，无法参加者须提前请假并发送书面进度报告。
- 团队沟通使用指定渠道（如微信群/飞书），重要决定须有书面记录。
- 遇到技术问题，优先在团队内部讨论，鼓励相互帮助。

## 3. 设备与安全规范

- 使用无人机前须完成安全培训，并熟悉相关法规。
- 飞行测试须在指定区域进行，不得擅自在禁飞区飞行。
- 设备使用后须归位并填写使用记录，发现损坏及时上报。
- 严禁在未经授权的情况下修改飞控参数或硬件配置。

## 4. 文档规范

- 所有技术文档须使用 Markdown 格式编写，存放于本仓库对应目录下。
- 文档修改须通过 Pull Request，不得直接在主分支编辑。
- 重要设计决定须有对应的设计文档或会议纪要记录。

## 5. 违规处理

违反上述规范的成员，视情节轻重，由团队负责人进行提醒、警告或取消相应权限等处理。

---

*本规范如有更新，以仓库最新版本为准。如有疑问请联系团队负责人。*
